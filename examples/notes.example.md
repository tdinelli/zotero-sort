# General rules

Research area: one or two sentences about what you work on. It helps with borderline papers.

- File each item in 1-3 collections: the most specific subcollection that fits.
- Never file into a parent that has subcollections.
- `Projects/*` only when I say the paper is for that project.
- If nothing fits, propose a new collection (name, parent, why).

# Tags

Only these; don't invent new ones. Tags are optional.

- type: `#review`, `#experiment`, `#theory`, `#method`, `#dataset`
- status: `#to-read`, `#key-paper` (only when I ask)
